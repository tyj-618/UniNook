# 演示与项目讲解指南

## 五分钟演示路径

1. 使用两个已绑定校园的测试账号登录，展示推荐范围与排序可在跨页面导航后保持。
2. 账号 A 发布校园讨论；账号 B 发表评论并进行二级回复，展示作者、评论点赞和评论定位。
3. 在帖子或一级评论上发起一个问题追踪。账号 B 订阅后，通过“快速作答”提交候选答复；账号 A 将其标记为通过。
4. 展示订阅者收到的状态通知，并从候选答复列表回到原帖子或“评论中的问题”区域。
5. 打开校园助手，说明其检索范围受校园可见性约束；检索服务不可用时仍可降级为关键词检索。

演示账号应在部署后单独注册，密码不写入仓库、截图或公开文档。公开演示前先用真实设备完成一次完整流程，避免使用遗留测试数据证明问题追踪绑定关系。

## 一分钟项目介绍

UniNook 是一个以高校和校区为边界的校园社区。项目使用 Vue 3 和 Spring Boot 构建，覆盖登录续期、校园可见范围、帖子评论、互动通知和问题追踪。为保证社区讨论可以落地，问题追踪采用“一篇帖子或一条一级评论对应一个问题”的约束：用户可以订阅、提交候选答复，发起者再完成或重新开启问题。系统还接入 Redis 缓存与限流、RocketMQ 事件分发，以及带权限过滤和降级策略的混合检索助手。

## 面试时可展开的工程点

- 鉴权：短期访问令牌保存在内存，刷新令牌通过 HttpOnly Cookie 续期；退出和异常刷新都会清理会话状态。
- 权限：推荐流和助手请求按校区、同校、距离或同城范围过滤；通知、历史和候选答复等直接访问链路不会错误受推荐范围阻断。
- 事件：评论、点赞和问题状态变化通过 Outbox 与消息队列异步分发，降低主请求与通知处理的耦合。
- 性能与可用性：热点内容、附近学校结果进入 Redis；搜索服务设有超时和 SQL 关键词降级，外部依赖异常不会阻断核心浏览。
- 部署：Compose 将基础服务限制在回环地址，Nginx 终止 HTTPS；健康检查、自动验证、部署与回滚步骤均已固化。

## 首轮展示边界

首个公开版本不扩展关注、私聊、收藏、二级评论提问、多问题轮询或复杂推荐模型。优先保证现有链路可重复演示、可部署、可恢复，并将每次修复记录为可验证的发布结果。
