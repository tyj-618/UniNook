# UniNook 5 分钟演示脚本

## 开场（30 秒）
"大家好，我演示的项目是 UniNook——一个面向大学生的地理位置校园社区，集成了 AI 校园助手。"

## 第一步：登录 + Feed（1 分钟）
1. 打开 joinuninook.com
2. 登录（展示登录页 UI）
3. 进入校园动态，展示：
   - 距离筛选（同校区/同校/10km/20km/同市）
   - 排序（最新/热门）
   - 帖子卡片（hover 效果）
   - 底部"加载更多"分页

## 第二步：帖子详情 + 问题追踪（1.5 分钟）
1. 点击一个帖子
2. 展示：
   - 帖子正文、作者、点赞
   - 右侧问题追踪面板（如果有）
   - 评论区（点赞、回复、举报）
3. 如果有问题追踪：展示候选答复、AI 审核、采纳流程

## 第三步：AI 助手（1.5 分钟）
1. 进入校园助手
2. 展示空状态引导卡片 + 示例问题
3. 点击一个示例问题（或自己输入）
4. 展示：
   - 流式输出（闪烁光标）
   - 参考帖子卡片
   - 👍👎 反馈按钮
5. 如果 AI 建议发帖：展示确认流程

## 第四步：管理后台（30 秒）
1. 切换到管理员账号
2. 展示：
   - 帖子管理（隐藏/恢复）
   - 举报管理（处理/驳回）
   - 反馈统计（低质量回答、高频问题）
   - 审计日志

## 结尾（30 秒）
"这就是 UniNook 的核心功能。技术上，我做了 RAG 混合检索、Agent 编排、SSE 流式、选择性降级等。代码开源在 GitHub，线上可以访问 joinuninook.com。谢谢！"
