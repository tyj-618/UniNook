# 首轮部署范围

UniNook 的首轮目标是完成可部署、可演示、可回归的校园社区闭环，而不是继续扩展功能数量。

## 本次冻结的核心闭环

- 校园范围内的帖子、评论和二级回复。
- JWT 身份认证、权限校验、点赞、通知和个人主页。
- 问题追踪：每篇帖子或每条一级评论一个问题；用户可订阅、提交候选答复、由发起者判断、结束或重新开启问题。
- Redis、RocketMQ、Elasticsearch 降级检索、Docker Compose 和部署文档。

## 首轮部署前不再扩展

- 同一帖子或评论的多问题、问题切换预览和多问题聚合。
- 关注、私信、积分、回答者排序、自动评审和新的社交玩法。
- 向量检索、流式输出或新的模型能力，除非修复当前闭环的阻断性缺陷。

首轮部署前的新增工作只接受三类：核心链路缺陷修复、回归验收、部署与演示材料。其余想法记录为后续迭代，不改变当前数据模型或交互主线。
